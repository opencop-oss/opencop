# Contributing to OpenCOP

Reproducible bug reports, including documentation errors, are welcome in
[GitHub Issues](https://github.com/opencop-oss/opencop/issues).

We are not currently accepting feature requests or external pull requests.
This applies to both code changes and documentation-only changes.

## Reporting a bug

Check existing issues for a matching report before opening a new one. Include:

- The OpenCOP version or commit you are using.
- Your environment, such as the operating system, browser and Docker version.
- The steps needed to reproduce the problem.
- What you expected to happen and what actually happened.
- Relevant logs, error messages or screenshots, with credentials, personal
  information and other sensitive data removed.

A small reproducible example helps us understand the problem. Do not include
private operational data in a public report.

## Reporting a documentation error

Identify the affected page or file, its section, what is incorrect and what you
expected instead. Include the version or commit of the documentation if known.
Documentation corrections should be reported as issues rather than pull requests.

## Reporting a security vulnerability

Report suspected vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
Do not include vulnerability details in a public issue.
